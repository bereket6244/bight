# Third-party notices

Bight is MIT licensed. This file records every third-party component it
depends on or redistributes, and the licence each is used under.

## A note on chess artwork

**Bight contains no third-party chess assets.**

The piece set (`src/ui/components/Pieces.tsx`), the board, the app icon and
the Bight wordmark are all original work created for this project and are
covered by Bight's own MIT licence.

This was a deliberate choice. The two obvious sources of ready-made pieces are
unsuitable for a permissively-licensed repository:

- **Lichess / cburnett pieces** are GPL-licensed. Bundling them would oblige
  the whole application to be distributed under the GPL.
- **Chess.com assets** are proprietary and were never an option.

Bight is not affiliated with, endorsed by, or connected to Lichess or
Chess.com. Their names, logos and trademarks are not used anywhere in the
application, its icon, or its store metadata. The green-and-cream board is a
plain CSS colour scheme, not a copy of any particular site's artwork.

## Redistributed model

| Asset | Licence | Notes |
| --- | --- | --- |
| `vosk-model-small-en-us-0.15` | Apache-2.0 | Offline English speech model. Apache-2.0 permits redistribution, so the model is packaged into the APK. It is **not** committed to this repository — it is ~39 MB of binary that every clone would otherwise pay for. Fetch it with `npm run fetch:voice-model` before building if you want voice answers. |

The Vosk model and the Vosk runtime are the work of Alpha Cephei Inc. and the
`vosk-browser` contributors respectively. Bight's voice grammar design — a
restricted per-exercise vocabulary rather than open dictation — follows the
approach Lichess uses in its own open-source Vosk integration. No Lichess code
is copied; the similarity is architectural.
